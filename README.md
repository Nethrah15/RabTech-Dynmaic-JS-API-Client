# RABTECH - Task 5 Dynamic JS DOM Logic & RESTful API Client

## API Used
FakeStoreAPI - https://fakestoreapi.com/products

## Features
- async/await fetch from public REST API
- Real-time search filtering (no page reload)
- Category tabs + Sorting (Price Low/High, A-Z)
- localStorage cart caching - cart stays after refresh
- Loading skeleton + Error banner handling
- Modular JS: api.js (API) + app.js (DOM Logic)

## How to Run
Open index.html with Live Server (VS Code)
